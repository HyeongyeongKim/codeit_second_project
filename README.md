- [현재 기준: 사업별 검색·기본 BM25](현재기준_사업식별_BGE-M3_기본BM25.ipynb)

가장 큰 개선은 **질문에서 사업을 식별해 해당 사업 문서만 검색한 것**이었습니다. 문서 정제와 청크 크기 변경의 효과는 아직 확정되지 않았습니다. Kiwi BM25는 30문항 검색 비교에서 유망했지만, 결과는 해당 질문과 설정에서만 해석해야 합니다.

노트북의 실행 출력과 API 키는 제외했습니다. 실행하려면 각 노트북에 적힌 RFP 문서, 목록 CSV, 평가 데이터와 Colab 비밀 설정이 필요합니다.
