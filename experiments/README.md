# RFP RAG 주요 실험

**큰 변경을 한 실험 21개를 시간순으로 모았습니다.** 파일 이름의 숫자는 진행 순서입니다. 작은 수정본과 같은 코드의 복사본은 뺐습니다. 실패한 시도도 남겼습니다.

| 파일 번호 | 실험 내용 |
| --- | --- |
| 01~03 | 초기 검색·HyDE·EXAONE, OpenAI 답변 생성 시도 |
| 04~07 | Dense+BM25+RRF, Qwen/RAGAS 평가, 문서 정제 비교 |
| 08~11 | 검색 수 확대, 사업별 검색, 청크 크기 변경 |
| 12~15 | 임베딩 모델과 기본·Kiwi BM25 비교 |
| 16~21 | 36·30문항 LangSmith 평가와 BM25 검색 단계 비교 |

**실행 방법:** 원하는 노트북 하나를 Colab에서 열고 위에서 아래로 실행합니다. 대부분 `/content/drive/MyDrive/data`의 RFP 문서와 `/content/drive/MyDrive/data_list.csv`를 사용합니다. 평가 파일은 `rag_eval_dataset.json` 또는 `rag_eval_dataset_3x10.json`이 필요합니다. API를 쓰는 노트북은 첫 셀의 안내에 따라 Colab 비밀에 키를 등록하세요.

**파일 설명:** 12~14번은 당시 비교 모델을 남아 있는 전체 코드에 적용한 재현용 파일입니다. 18번은 Claude 채점 오류가 있었던 시도입니다. 19~21번은 한 노트북에 섞인 기본 BM25, Kiwi BM25, 검색 비교를 각각 분리했습니다. 실행 출력·원본 문서·결과 파일·API 키는 넣지 않았습니다. 21번의 실행 결과 JSON에는 문서 본문이 들어가므로 공개 저장소에 올리지 마세요.

실험의 결과와 한계는 [실험 기록](../RAG_실험_기록.md)과 [10월 8일 상세 보고서](../2026-10-08_RAG_상세_보고서.md)에 있습니다. 10월 8일 청킹 결과는 보고서와 파일명 사이에 불일치가 있어 우열을 확정하지 않았습니다.
